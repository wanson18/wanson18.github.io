Privacy Policy — Wanson Automation

Last updated: 7 November 2026

Wanson Automation is a private tool used only by Wanson Enterprise and Wanson Enterprise (M) Sdn. Bhd. for their own internal operations.

What data it accesses

With the owner's permission, it reads the owner's own Gmail messages (read-only), Google Sheets and Google Drive files that relate to the business's stock records, invoices and supplier documents.

How the data is used

The data is used only to prepare the business's own stock books, statutory reports and internal records. It is not sold, shared with third parties, or used for advertising.

Storage and retention

Data is processed on the business's own computers and private cloud runner, and kept only as long as needed for the business's records. Access can be revoked at any time from the Google Account permissions page.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
